Site privacy

This page is about the site platizhka.com.ua, not about the app. The app has no servers and sends nothing anywhere; its own policy is here.

The site has no accounts, no forms, no comments and no advertising scripts. There is no way to send us any data through it — only to write an email, if you choose to.

What is stored in your browser

One value: your chosen theme, light or dark, in localStorage. It exists so the page does not flash a light background before the dark one applies. That value never leaves your browser.

The site sets no cookies at all.

Visit statistics

We use Cloudflare Web Analytics. Cloudflare states that it uses no cookies or localStorage and does not build a fingerprint from IP addresses or User-Agent strings.

What we see are aggregate numbers: how many page views there were, which links and search engines visitors arrived from, which country, which browser, operating system and device type, and how quickly pages loaded. No individual person is visible in that data, and we cannot connect one visit to another.

Why we want it: to know which blog topics are worth writing next, and to see whether the site is slow on real phones.

Hosting

The site is static files on GitHub Pages. Like any web server, GitHub sees the technical details of the request, including the IP address and User-Agent, and processes them under its own policy. We have no access to those logs.
